# SIGECO-SOG
### Sistema de Información Georreferenciada para la Caracterización y Conexión de Emprendimientos de Sogamoso, Boyacá.

SIGECO-SOG es una plataforma web desarrollada como **proyecto académico universitario**, orientada a organizar, caracterizar, georreferenciar y consultar información de establecimientos comerciales, emprendimientos y unidades productivas del municipio de Sogamoso, Boyacá.

El proyecto busca facilitar el reconocimiento de la oferta comercial y productiva local mediante herramientas digitales que permiten visualizar ubicaciones geográficas, consultar información de los establecimientos y gestionar los datos de manera centralizada.

### Funcionalidades principales

- Registro, consulta, edición y administración de establecimientos.
- Clasificación de establecimientos mediante categorías.
- Visualización geográfica de la información.
- Sistema de autenticación y gestión de usuarios.
- Administración de permisos mediante roles.
- Interfaz web intuitiva y adaptable.
- Panel administrativo para la gestión de la información.

### Tecnologías utilizadas

- HTML, CSS y JavaScript.
- Supabase para base de datos y autenticación.
- Git y GitHub para el control de versiones.

### Propósito académico

SIGECO-SOG se desarrolla en el marco de un proyecto universitario de la Universidad Nacional Abierta y a Distancia (UNAD), con fines académicos y tecnológicos, como iniciativa orientada al fortalecimiento de la visibilidad y organización de los emprendimientos y unidades productivas de Sogamoso.
